# Airline Passenger Satisfaction & Flight Operations Dashboard (Power BI)

## 📌 Project Overview
An interactive Power BI dashboard analyzing passenger satisfaction, flight operations, and service quality ratings across 130K flight records. The report evaluates how flight delays, travel classes, and onboard services impact overall customer satisfaction.

## 📊 Key Insights & Metrics
* **Total Passengers & Flights:** 130K records analyzed.
* **Flight Delays:** Average arrival delay of **15.05 mins** and departure delay of **14.71 mins**.
* **Satisfaction Rate:** **43.45%** overall customer satisfaction rate.
* **Demographics:** Balanced breakdown between female (49.26%) and male (50.74%) passengers.
* **Travel Class:** Business class accounts for the highest passenger count and satisfaction compared to Eco and Eco Plus.
* **Service Ratings:** Baggage handling and seat comfort scored highest, while Inflight Wi-Fi received the lowest satisfaction score.

## 🛠️ Tools & Technologies Used
* **Power BI Desktop:** Data modeling, DAX measures, and visual design.
* **Power Query:** Data cleaning, transformation, and attribute encoding.
* **Data Visualizations:** KPI Cards, Stacked Bar Charts, Donut Charts, and Column Charts.
